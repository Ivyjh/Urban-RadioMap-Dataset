# Urban-RadioMap-Dataset
A multi-scenario and multi-modal RadioMap dataset for urban wireless propagation prediction. The dataset contains RadioMaps generated by ITU-R P.1411 and ray tracing models, including static and dynamic urban scenarios with building, transmitter, vehicle, and received signal strength information.
